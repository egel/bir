# AGENTS.md

Guidelines for AI agents working in this repository.

## Writing style

- Do NOT use em dashes (`—`) or en dashes (`–`) in any file (code, docs,
  README, comments). Use a comma, colon, or a separate sentence instead.
- The same applies to stylistic "pauses" (e.g. `...` ellipses used for
  dramatic effect). Write direct, plain sentences.
- Em dashes are essentially never used by modern writers; avoid them
  entirely rather than occasionally.

## General

- Keep the existing code style, naming, and file structure consistent.
- Follow the conventions already present in the surrounding code.
